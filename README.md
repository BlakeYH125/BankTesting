# Управление операциями банковского счета

Небольшое учебное консольное приложение на Java. Оно не использует Spring,
Docker и настоящую базу данных. Хранилище имитируется классом
`AccountRepository`: `ArrayList` играет роль таблицы, а каждая `HashMap` — строки.

## Что умеет программа

- открывать и закрывать счета;
- пополнять счет и снимать деньги;
- переводить деньги между счетами;
- блокировать и разблокировать счет;
- менять имя владельца;
- считать количество счетов и общий баланс банка;
- находить счета владельца и самый богатый счет;
- начислять бонус за пополнение и рассчитывать комиссию.

В `BankService` находится 24 небольших публичных метода. Над каждым методом
указан его номер и краткое назначение.

## Структура

```text
src/main/java/ru/bank/
├── AccountRepository.java  — имитация таблицы в памяти
├── BankService.java        — банковские операции
└── BankConsoleApp.java     — консольное меню
```

## Запуск

Нужна только Java 17 или новее. Gradle Wrapper уже находится в проекте.

```bash
./gradlew run
```

Когда тесты будут написаны, их можно запустить командой:

```bash
./gradlew test
```
